# ZMSL Web Official Site

This is the official website for ZMSL, built with Next.js and Ant Design.

## Getting Started

1.  **Install dependencies** (if not already done):
    ```bash
    npm install
    ```

2.  **Run the development server**:
    ```bash
    npm run dev
    ```

3.  **Open the website**:
    Open [http://localhost:3000](http://localhost:3000) with your browser.

## Features

-   **Home**: Introduction and features.
-   **Download**: Get the latest ZMSL client.
-   **Changelog**: View version history.
-   **Docs**: User documentation.
-   **User Center**: Manage your account and FRP tunnels.

## Backend Integration

This frontend connects to the ZMSL API backend running on `http://localhost:5000`.
Ensure the backend service (`ZMSL.Api-Java`) is running.

## Technology Stack

-   **Framework**: Next.js 16 (App Router)
-   **UI Library**: Ant Design 6
-   **Icons**: @ant-design/icons
-   **Language**: TypeScript
